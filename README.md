A highly interactive and modern web developer portfolio, built using React and modern 3D rendering technologies to create a dynamic user experience.

## ✨ Key Features

This project utilizes cutting-edge web technologies to deliver a sophisticated and visually rich experience:

* **Immersive 3D Graphics:** Utilizes `Three.js` and `React Three Fiber` for high-performance 3D components and visual effects.

* **Smooth Animations:** Leverages the `motion` library for fluid, declarative UI animations.

* **Responsive Design:** Ensures a seamless experience across all devices (mobile, tablet, desktop).

* **Professional Timeline:** Showcases experience and education using a dedicated vertical timeline component.

* **Integrated Contact Form:** Functional contact form powered by EmailJS.

* **Modern Styling:** Styled efficiently using **Tailwind CSS**.

## 💻 Technologies Used

This project is built using a modern stack focused on performance and developer experience.

### Core Stack

| Category | Technology | Purpose |
| :--- | :--- | :--- |
| **Framework** | `React` (v19) | Frontend user interface development. |
| **Build Tool** | `Vite` | Fast development environment and bundling. |
| **Styling** | `Tailwind CSS` | Utility-first CSS framework for rapid, responsive styling. |

### Major Dependencies

| Library | Package Names | Description |
| :--- | :--- | :--- |
| **3D & Graphics** | `three`, `@react-three/fiber`, `@react-three/drei`, `cobe`, `maath` | Core libraries for creating and rendering 3D scenes and beautiful globe effects. |
| **Animation** | `motion` | Advanced library for handling complex, physics-based animations. |
| **UI Components** | `react-vertical-timeline-component` | Dedicated component for structuring professional history. |
| **Forms** | `@emailjs/browser` | Enables sending emails directly from the client side without needing a dedicated backend server. |
| **Utilities** | `react-responsive`, `tailwind-merge` | Helpers for handling media queries and conditionally merging Tailwind classes. |
